BENALSUR GESTIÓN — PWA V1

Esta carpeta contiene una PWA instalable.
IMPORTANTE: para que iPhone muestre “Añadir a pantalla de inicio” como app y funcione el modo offline, los archivos deben estar publicados mediante HTTPS. Abrir index.html directamente desde Archivos no instala la PWA.

Incluye:
- Logo e iconos Benalsur
- Calendario mensual
- Reservas Booking/Airbnb/directas
- Comisión, IVA, cargo de pagos y neto
- Gastos
- Precio recomendado Minerva/Júpiter
- Simulación orientativa de Hacienda
- Gastos fijos mensuales de partida: 799,91 €
